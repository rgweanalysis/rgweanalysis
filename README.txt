RGWE + RSWE Sites Portal
========================

Upload these files to the ROOT of the same GitHub repository:

1. index.html          -> Main gateway with RGWE Site and RSWE Site cards
2. rgwe-site.html      -> Existing RGWE tools platform
3. rswe-site.html      -> RSWE platform with the Supply Flow card
4. rswe-kitchen.html   -> RSWE Supply Flow application
